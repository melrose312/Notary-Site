# Lorelle Notary Services

I built this website for a local notary public service to give their business a clean, modern look that builds trust with clients. It’s designed to feel professional yet approachable, especially since Lorelle is a small business. It's perfect for that local service feel.


This is a 2-page static website built to promote local notary services. The site features:


## Features

Responsive Design: Fully responsive layout optimized for desktop, tablet, and mobile devices.

Modern UI/UX: Clean typography, gradient accents, subtle animations, and hover effects.

Fixed Navigation: Sticky header with smooth scrolling navigation.

Contact Form: Client side validated form with a service selection dropdown.

Accessibility: Built with semantic HTML5 structure, proper labeling, and descriptive metadata.

SEO Optimization: Includes meta descriptions and a clear heading hierarchy to improve search visibility.


## Developer Notes

This project really highlights what I’ve been learning and refining: building responsive, websites with clean, maintainable CSS (using a BEM-style approach). I focused on creating modern UI elements like cards, buttons, forms, and smooth navigation while keeping accessibility and SEO best practices in mind. Plus, I added some subtle animations and transitions to make everything feel more polished and dynamic.
